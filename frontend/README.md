# MisFinanzas — Frontend

Aplicación Angular de MisFinanzas, construida sobre la plantilla
[CoreUI Free Angular Admin Template](https://github.com/coreui/coreui-free-angular-admin-template)
(licencia MIT, ver `LICENSE`).

Instrucciones de instalación, desarrollo y despliegue en el [README principal](../README.md).

## Comandos

```bash
npm install
npm start                              # servidor de desarrollo en http://localhost:4200
npx ng test --watch=false              # tests (Vitest + Chromium headless)
npx ng build --configuration production
```
